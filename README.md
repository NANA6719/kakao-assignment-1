# Todo App

> 날짜별 Todo를 생성하고 관리할 수 있는 Vanilla JavaScript 기반 생산성 웹 애플리케이션

## 주요 기능

* Todo 생성(Create)
* Todo 조회(Read)
* Todo 수정(Update)
* Todo 삭제(Delete)
* Todo 완료 처리
* 상태별 필터링 (ALL / ING / CLEAR)
* 날짜별 Todo 관리
* 주간 뷰 제공
* Local Storage 데이터 저장
* 새로고침 시 데이터 유지

## 실행 방법

1. 프로젝트를 다운로드한다.
2. `index.html` 파일을 실행한다.
3. Todo를 생성하고 날짜별로 관리한다.

## 사용 기술

* HTML5
* CSS3
* Vanilla JavaScript
* Local Storage
